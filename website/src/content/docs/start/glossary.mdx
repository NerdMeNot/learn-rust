---
title: "Glossary: Rust words in plain English"
description: "Look up a Rust word, see what it means in plain words, the closest idea in Go, Java, Kotlin, C#, Python, TypeScript, C or C++, and the lesson that teaches it."
---

You will meet words in Rust code, compiler messages and docs that no other language uses. This page gives each a plain meaning, the closest idea you may already know, and the lesson section that teaches it. Symbols come first, then A to Z. A word that a lesson only mentions in passing is explained in one line here.

## Symbols

| Word | Plain meaning | You may know it as | Taught in |
| --- | --- | --- | --- |
| **`'a`** | A lifetime name that ties a returned reference to the inputs it borrows from. | None in Go, Java, Kotlin, C#, Python or TypeScript. | [Lifetimes](/learn/lifetimes/#naming-a-lifetime-a) |
| **`'static`** | A lifetime that lasts the whole run of the program; as a bound, `T: 'static` means `T` holds no borrow that could end early. | Not C's `static`. | [Lifetimes](/learn/lifetimes/#static) |
| **`?`** | After a `Result` or an `Option`, it takes the value out, or returns the failure from the whole function right now. | Go: the `if err != nil { return err }` pair, in one character. Not a ternary, not `?.`. | [Errors and Result](/learn/errors/#-pass-the-error-up) |
| **`!`** after a name | Marks a macro call, as in `println!`. | C: nothing at the call shows a macro. | [Macros, attributes and comments](/learn/macros-attributes-naming/#the--a-macro-call) |
| **`&T`** | A shared reference: the address of a value that already exists, read-only, owning nothing. | C++: close to `const T&`, but the compiler checks it cannot outlive the value. | [Borrowing](/learn/borrowing/#a-reference-is-a-read-only-address) |
| **`&mut T`** | A mutable reference: it may change the value it points at, and while it exists nothing else may use that value. | C#: `ref` is the nearest form. C++: close to `T&`, with the one-writer rule checked. | [Mutable Borrows](/learn/mutable-borrows/#mut-lend-a-value-to-be-changed) |
| **`::`** | Walks a path to a name, such as a module, a type or a function; `.` works on a value you hold. | C++: `::` is also a path. | [Rust at a glance](/learn/rust-at-a-glance/#paths-and-dots) |
| **`@`** | In a pattern, tests a pattern and names the value in one step, as in `n @ 1..=9`. | Python: `case 1 \| 2 \| 3 as n` in `match`. | [Match](/learn/match/#names--and-guards) |
| **`_`** | A pattern that fits anything and binds nothing; `_name` is a real variable that only silences the unused warning. | Go and Python: `_`. | [Patterns](/learn/patterns/#_-ignores-_name-binds) |

| Word | Plain meaning | You may know it as | Taught in |
| --- | --- | --- | --- |

| **associated function** | A function in an `impl` with no `self`, called with `::` on the type, like `Account::new`. | Java, C#: a static method. Kotlin: a companion-object function. | [Methods](/learn/methods/#functions-without-self-new-self-and-constants) |
| **associated type** | A type that a trait leaves for each implementing type to choose, like `Item` in `Iterator`. | Close to an interface's type parameter, but the implementer fixes it once. | [Traits](/learn/traits/#associated-types-and-constants) |
| **`async`** | Marks a function or block whose body becomes a future: nothing runs until it is `.await`ed or handed to a runtime, and the standard library has no runtime. | C#, Python, TypeScript: `async` and `await`. Python coroutines are also lazy; C# tasks and JavaScript promises start at once. | [Async Basics](/learn/async-basics/), [Async with Tokio](/build/tokio/) |
| **attribute** | A note to the compiler about the item after it, written `#[...]`, or `#![...]` for the item it sits inside. | Java: annotation. C#: attribute. Not a Python decorator. | [Macros, attributes and comments](/learn/macros-attributes-naming/#attributes-) |

## D

| Word | Plain meaning | You may know it as | Taught in |
| --- | --- | --- | --- |
| **dangling reference** | A reference to something that is gone; in safe Rust the compiler refuses a program that would make one. | C and C++: dangling pointers compile. | [Borrowing](/learn/borrowing/#how-long-a-borrow-lasts) |
| **data race** | Two threads using the same memory at the same time, at least one writing, with nothing coordinating them. | The same term in Go, Java and C++; in C++ it is undefined behaviour. | [Mutable Borrows](/learn/mutable-borrows/#what-the-rule-buys), [Shared state](/learn/shared-state/#what-rust-refuses) |
| **`Debug`** | The trait behind `{:?}`: a form meant for programmers, which `#[derive(Debug)]` writes for you. | Python: `repr`. Go: close to `%v`. | [Macros, attributes and comments](/learn/macros-attributes-naming/#format-strings) |
| **`Default`** | A trait that makes a "blank" value, for `T::default()` and `..Default::default()`. | Close to Go's zero value, but only types that opt in have one. | [Common Traits](/learn/common-traits/#starting-from-a-default) |
| **deref coercion** | Where the type is known, the compiler turns a `&String` into a `&str`, and a `&Vec<T>` into a `&[T]`, by itself. | None. | [Borrowing](/learn/borrowing/#string-becomes-str-by-itself) |
| **derive** | `#[derive(...)]` asks the compiler to write standard trait code for a type from its fields. | Close to a Kotlin `data class` or Java `record`, but those also declare the fields and constructor; `derive` only adds trait code to a struct you declare, and you pick each trait. | [Structs](/learn/structs/#derive-asking-the-compiler-for-standard-behaviour) |
| **destructuring** | Taking a value apart with a pattern, so each name gets its part. | Python: unpacking. TypeScript: destructuring. C#: deconstruction. | [Patterns](/learn/patterns/#patterns-stand-in-many-places) |
| **discriminant** | The number each variant of a data-free enum has, starting at 0 or at the value you give it. | C: the value of an enum constant. Java: `ordinal()`. | [Enums](/learn/enums/#enums-with-no-data-are-numbers-underneath) |
| **`Display`** | The trait behind `{}` and `.to_string()`: text for the people who use the program, which you write yourself. | Java: `toString()`. Python: `__str__`. Go: `String()`. | [Common Traits](/learn/common-traits/#printing-debug-and-display) |
| **`Drop`** | A trait whose `drop` method runs when a value goes out of scope. | C++: a destructor. Go: `defer` is close. | [Ownership and Moves](/learn/ownership/#scopes-drop-order-and-let-_) |
| **`dyn`** | Marks a type known only by the trait it has; which method runs is looked up at run time. | Go: an interface value. Java: an interface reference. | [Trait Objects](/learn/trait-objects/#a-value-whose-type-you-have-forgotten) |
| **dynamic dispatch** | Choosing the method to run at run time, through a vtable. | Java: an ordinary interface call. C++: a virtual call. | [Traits](/learn/traits/#static-and-dynamic-dispatch-in-one-program) |

## E

| Word | Plain meaning | You may know it as | Taught in |
| --- | --- | --- | --- |
| **edition** | A named set of language rules that a package picks in `Cargo.toml`, so Rust can change without breaking old code. | C++: the `-std=` choice is close. | [Hello World](/learn/hello-world/#editions) |

## F

| Word | Plain meaning | You may know it as | Taught in |
| --- | --- | --- | --- |
| **fat pointer** | A pointer plus a second word: for a slice or `&str`, the length; for `dyn`, the address of the vtable. | Go: an interface value is also two words. | [Trait Objects](/learn/trait-objects/#what-a-dyn-pointer-is-made-of) |

## M

| Word | Plain meaning | You may know it as | Taught in |
| --- | --- | --- | --- |
| **macro** | Code that the compiler expands into other code before it checks types; the `!` marks a call. | C: a preprocessor macro, but this one takes tokens, not text. | [Macros, attributes and comments](/learn/macros-attributes-naming/#the--a-macro-call) |
| **`match`** | Compares one value with a list of patterns and gives the value of the first that fits; it must cover every case. | Kotlin `when`, Java and C# `switch` expressions, Python `match`. A C-style `switch` is further off: it only compares numbers. | [Match](/learn/match/#match-is-an-expression) |
| **method** | A function with a `self` first parameter, defined in an `impl` and called with a dot. | A method, as in Java, Kotlin, C# and Python. | [Methods](/learn/methods/#a-method-is-a-function-with-a-self-parameter) |
| **module** | A named group of items that hides whatever you do not mark `pub`; it is also the privacy boundary. | Go, Java: a package. C#: a namespace (not a privacy line). | **monomorphization** | The compiler writes a separate copy of a generic function for each type it is used with. | C++: template instantiation. | [Generics](/learn/generics/#one-copy-per-type) |
| **move** | Handing a value to a new owner; the old name can no longer be used. | C++: `std::move`, but using a moved-from value does not compile here. | [Ownership and Moves](/learn/ownership/#moves) |
| **`move` (closure)** | Before the bars of a closure, makes it take every variable it uses by value. | None. | [Closures](/learn/closures/#move-take-ownership) |
| **`mut`** | Lets a variable change; it belongs to the name, not to the value. | Kotlin: `var`. Java: a variable that is not `final`. But Kotlin `val` and Java `final` stop only reassignment; Rust's plain `let` also stops changing the contents. | [Variables](/learn/variables/#frozen-unless-you-say-mut) |

## O

| Word | Plain meaning | You may know it as | Taught in |
| --- | --- | --- | --- |
| **`Option`** | An enum that is `Some(value)` or `None`; safe Rust has no null references. | Close to Java's `Optional<T>` or Kotlin's `T?`. | [Option](/learn/option/#what-option-is) |

## S

| **smart pointer** | A type that owns a value behind a pointer, such as `Box`, `Rc` and `Arc`. | C++: smart pointers, the same term. | [Smart pointers](/learn/smart-pointers/#what-makes-a-pointer-smart) |
| **stack** | The memory that holds each call's frame; fast, and everything on it has a size known when compiled. | The call stack in every language.
